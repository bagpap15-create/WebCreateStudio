# 🚀 WebCreate Studio - Portfolio Website

Καλώς ήρθατε στο αποθετήριο του **WebCreate Studio**! Αυτό το project αποτελεί το προσωπικό μου portfolio, σχεδιασμένο και αναπτυγμένο εξ ολοκλήρου από το μηδέν με καθαρό κώδικα (custom code), με σκοπό να αναδείξει τις δεξιότητές μου στο Full-Stack Web Development και το UI/UX Design.

🔗 **Δείτε το project ζωντανά εδώ:** [WebCreate Studio Live](https://freehosting.dev)

## 💡 Φιλοσοφία & Στρατηγική UX
Το μέλλον του web design δεν ανήκει απλώς στον αυτοματοποιημένο κώδικα ή στα έτοιμα templates, αλλά στον **συνδυασμό της ανθρώπινης στρατηγικής και της ενσυναίσθησης (empathy)** με τα σύγχρονα ψηφιακά εργαλεία. 

Κατά τον σχεδιασμό αυτής της ιστοσελίδας, δόθηκε ιδιαίτερη έμφαση:
* **User Experience (UX):** Καθαρή δομή, εύκολη πλοήγηση για τον χρήστη και άμεση πρόσβαση στις πληροφορίες.
* **Responsive Design:** Πλήρης συμβατότητα και βέλτιστη οπτική εμπειρία σε desktop, tablets και mobile συσκευές.
* **Ψηφιακή Ανάπτυξη:** Στρατηγική δόμηση ενοτήτων (Υπηρεσίες, WordPress, E-shop, SEO) με επίκεντρο τις ανάγκες των σύγχρονων επιχειρήσεων.

---

## 🛠️ Τεχνολογίες που Χρησιμοποιήθηκαν

Το project είναι αναπτυγμένο με custom αρχιτεκτονική, χωρίς τη χρήση έτοιμων CMS templates:
* **Frontend:** HTML5, CSS3 (Custom Grid/Flexbox), JavaScript (DOM Manipulation & Interactions)
* **Backend:** PHP (Δυναμική διαχείριση περιεχομένου και δομή σελίδων)
* **Hosting/Environment:** Φιλοξενία σε PHP/MySQL περιβάλλον με πλήρη διαχείριση μέσω Git

## 📈 Μελλοντικές Βελτιώσεις (Roadmap)
Η ιστοσελίδα εξελίσσεται συνεχώς. Στα επόμενα βήματα περιλαμβάνονται:
1. Σύνδεση με custom domain name (`.gr`) για πλήρη εταιρική ταυτότητα.
2. Ενσωμάτωση δυναμικής βάσης δεδομένων (MySQL) για τη διαχείριση των projects.
3. Περαιτέρω βελτιστοποίηση του Core Web Vitals (SEO & Ταχύτητα φόρτωσης).
